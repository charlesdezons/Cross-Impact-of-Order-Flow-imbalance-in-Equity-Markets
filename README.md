# Cross-Impact-of-Order-Flow-imbalance-in-Equity-Markets
This is a repository discussing a paper from Rama Cont, Mihai Cucuringu &amp; Chao Zhang about Cross-impact of order flow imbalance in equity markets. There is also a python code implementing some of the methods seen in the paper with the ultimate goal of predicting stock returns by regressing Cross-Sectional Order Flow Imbalances on returns.
